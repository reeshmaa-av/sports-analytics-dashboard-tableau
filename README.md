# Olympic Athlete Performance & Medal Analytics Dashboard
# Overview

This project is an interactive Tableau dashboard designed to analyze Olympic athlete performance, medal achievements, participation trends, and country-level sports success. The dashboard provides insights into how nations and athletes have performed across different Olympic Games over time.

The goal of this project is to transform raw Olympic data into meaningful visual insights that help identify performance patterns, participation growth, and medal-winning trends.

# Objectives
Analyze Olympic medal distribution across countries.
Identify top-performing nations based on medal count.
Explore athlete participation trends over time.
Examine the relationship between first participation year and total medals won.
Discover popular sports categories and successful athletic programs.
Provide interactive visualizations for sports analytics and decision-making.
